# Campus Companion — Bootstrap UI/UX Mini Project

## Technologies
- HTML5
- Bootstrap 5.3.3 CSS (CDN)
- Custom CSS
- No JavaScript
- No backend/database (static UI/UX demonstration)

## Pages
1. Home Dashboard
2. Timetable
3. Attendance
4. Notices
5. Events
6. Faculty Directory
7. Campus Locator
8. Student Profile

## Run in VS Code
1. Extract the ZIP.
2. Open the `Campus_Companion_Bootstrap_UIUX` folder in VS Code.
3. Open `index.html` in a browser (or use Live Server if installed).
4. Use the navigation links to move between pages.

## Important notes
- Internet is required to load Bootstrap CSS and remote event/hero images.
- All page navigation uses ordinary HTML links.
- The navigation is deliberately always visible and wraps on small screens, so it works without JavaScript.
- Sample student/faculty/attendance/timetable/notice/event information must be replaced with verified details before submission.
- This project demonstrates UI layouts and navigation. It does not provide login, live attendance, editable records, or a database.


## CSS-only interactive features
- Hover and keyboard-focus effects on navigation, cards and buttons.
- Expand/collapse information on Notice Board, Events and Campus Locator using native HTML details/summary.
- Smooth in-page navigation and responsive Bootstrap grid layout.
- No JavaScript, PHP, database or backend is used. All displayed information is sample/static content.
